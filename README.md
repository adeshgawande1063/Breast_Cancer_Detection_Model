# Breast Cancer Detection Using Machine Learning

## Project Overview
This project explores the use of machine learning to classify breast cancer cases as **Benign** or **Malignant** using diagnostic features.

The project uses Python for data analysis, preprocessing, model development, and prediction.

## Dataset
The dataset contains diagnostic measurements used to predict the classification of breast cancer cases.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Workflow
1. Load and explore the dataset.
2. Perform data preprocessing.
3. Prepare the features and target variable.
4. Train a machine learning classification model.
5. Predict the diagnosis for test samples.
6. Evaluate model performance.

## Diagnosis Classes
- **Benign:** Non-cancerous classification.
- **Malignant:** Cancerous classification.

## Project Files
- `Breast_cancer_Diagnosis.ipynb` — Notebook containing the project workflow.
- `breast_cancer_dataset (1).csv` — Dataset used for analysis.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the cells in sequence.
